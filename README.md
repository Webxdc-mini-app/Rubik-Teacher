# ルービックキューブ先生

3×3のルービックキューブをカメラで読み取り、初心者向けの7ステップで解き方を案内するwebxdcアプリです。日本語の説明と3Dプレビューを見ながら、実物のキューブを1手ずつ動かせます。

対象ファイル：`Rubik_s_Cube_Teacher-1.0.1.xdc`  
バージョン：`1.0.1`

## 主な機能

- 6面のカメラスキャンと、読み取った色の手動修正
- カメラを使わない手入力
- 各面の中心色を指定するカスタム配色設定
- 展開図・3Dプレビューによる入力内容の確認
- 7ステップの解法、日本語の回転説明、回転記号の表示
- 手順の前後移動、自動再生、先頭への移動
- 同じ面の連続回転や往復手の整理と、整理前後の手数表示

## 起動方法

1. webxdc対応のDelta Chatで `.xdc` ファイルをチャットに添付します。
2. 添付したアプリを開きます。
3. 実物の3×3キューブを用意します。

カメラが利用できるかは実行環境によって異なります。利用できない場合も、手入力で進められます。

## 使い方

### 1. 中心の色を設定する

ホームの「中心の色を設定して始める」から、上・右・前・下・左・後ろの中心色を選びます。6色を重複なく1回ずつ指定してください。

標準配色と「下=青／後=黄」のプリセットがあります。標準配色のままスキャンへ進むこともできます。

### 2. 6面を入力する

面を選び、画面の持ち方ガイドに合わせてキューブを向けます。カメラ使用時は3×3の枠に面を合わせ、「しゃしんをとる」を押してください。

読み取った色を確認し、誤りがあればマスをタップして修正します。色は **白→赤→緑→黄→橙→青** の順に切り替わります。中心のマスは配色設定の色に固定されます。

カメラが使えない場合は「手で色を入れる」パネルを使います。「この面OK」で確定し、6面すべてを入力してください。面ごとの向きをそろえることが大切です。

### 3. 入力内容を確認する

「かくにんへ」から、54マスの展開図と3Dプレビューを確認します。

- 各色が9マスずつあること
- 中心の色が配色設定と一致すること
- 中心色の重複がないこと

間違いがあれば「スキャンに戻る」で修正し、確認できたら「とく手順を見る」を押します。

### 4. 手順に沿って回す

画面で示された前の面を自分に向け、上の面を上にして持ちます。回転記号と日本語の説明に従い、実物のキューブを動かしてください。

「すすむ」「もどる」で手順を切り替え、「自動で再生」で順に表示できます。自動再生は「とめる」で停止できます。「最初から」は手順の先頭に戻る操作です。

## 解法の7ステップ

| ステップ | 目標 |
| --- | --- |
| 1 | 白い十字を作る |
| 2 | 白い角をそろえる |
| 3 | 真ん中の段をそろえる |
| 4 | 白の反対色の十字を作る |
| 5 | 白の反対色の面をそろえる |
| 6 | 角の位置をそろえる |
| 7 | 辺の位置をそろえて完成する |

画面のステップ名は配色設定に合わせて変わります。標準配色では白の反対色は黄色です。

## 回転記号

| 記号 | 面 |
| --- | --- |
| U | 上 |
| R | 右 |
| F | 前 |
| D | 下 |
| L | 左 |
| B | 後ろ |

文字だけなら、その面を正面から見て時計回りに90度回します。`'` は反時計回りに90度、`2` は180度です。たとえば `R U R' U'` は、右・上・右の逆回転・上の逆回転の順に動かします。

## 困ったとき

- **カメラが映らない：** 実行環境のカメラ権限を確認するか、手入力を使ってください。
- **色を読み間違える：** 明るい場所で反射を避けて撮り直すか、読み取り後のマスをタップして修正してください。
- **解法の計算でエラーになる：** 各面の向き、色の数、中心色を確認してください。各色が9マスずつでも、実物では成立しない配置になる場合があります。
- **「もう解けてるよ！」と表示される：** 入力した状態は完成済みと判定されています。実物が未完成なら入力を見直してください。
- **途中から実物と表示が合わない：** 持ち方と回転方向を確認してください。状態が分からなくなった場合は、現在の6面を入力し直します。

## 保存と通信

配色設定はメモリ内で扱われ、リロードすると標準設定に戻ります。進捗の永続保存やチャット参加者間の状態同期を行う処理は、同梱コードでは確認できません。

画面・スタイル・解法処理は同梱されています。カメラ映像はブラウザ内の色判定に使われ、外部サーバーへ画像を送信する処理は同梱コードでは確認できません。

## パッケージ構成

```text
Rubik_s_Cube_Teacher-1.0.1.xdc
├── manifest.toml   アプリ名・バージョン・起動ファイルの設定
├── index.html      画面・スタイル・JavaScriptを含む本体
└── icon.png        アプリアイコン
```

ReactとTailwind CSSを含む単一HTML形式のアプリです。展開した `index.html` をブラウザで開く場合、カメラの利用条件はブラウザと開き方によって異なります。
